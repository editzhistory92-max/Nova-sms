Test SMS Generator

System Master › Development & QA

Temporary QA Testing Tool

Generate test SMS records through the same processing logic used by production incoming SMS. This module is controlled by a feature flag and can be disabled anytime.
Supported placeholders: {code}, {number}, {index}

Generate Test SMS

Select an allocated number, or leave empty to use recently allocated client numbers.
Generated messages are marked as test in the database and can be cleared later. They still update dashboards, reports, stats, notifications and earnings so the full workflow can be tested.

Test Data Control

Use this after QA to remove generated test SMS records.
This clears records created by the Test SMS Generator only. Real carrier SMS records are not removed.
